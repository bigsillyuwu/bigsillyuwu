<h3 align="center">Learning something new every day.</h3>

I build React and Next.js interfaces that try to feel obvious and effortless, the kind where you don't notice the details because they quietly work. Lately I've been drawn to the overlap between web performance, design systems, and accessibility — the space where a component is fast, reusable, and usable by everyone at once. I think a lot about whether the abstractions we create actually serve the people clicking through them, or just the developers writing them.
